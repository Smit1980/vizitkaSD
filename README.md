# Шандалин Денис Анатольевич — визитка

Статическая страница-визитка: эксперт по внедрению ИИ в образование и бизнес, Клуб «ИИ в образованИИ», Агентство Новых Перспектив.

Живая страница: https://smit1980.github.io/vizitkaSD/

Zero-build: `index.html` + картинки в `img/`. Публикуется через GitHub Pages из ветки `main`.

Оформление — тёмный фон, акцент ember, анимации появления, переливание имени и кнопки
с выезжающей заливкой — перенесено из визитки https://smit1980.github.io/shandalin-vizitka/.
Анимируются только `transform` / `opacity` / `background-position`; системная настройка
«меньше движения» выключает движение полностью.
